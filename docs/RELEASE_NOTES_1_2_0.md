# Omnichannel Support 1.2.0

Disponible para Twenty CRM 2.50.

- **Conversaciones.** El título abre la ficha de Twenty. La acción **Vista previa** permite consultar el historial desde la bandeja.
- **Etiquetas.** Filtra por etiquetas y etiquetas propias en Conversaciones y FAQs. Los filtros de la bandeja se pueden guardar en una vista.
- **Dashboards.** Elige el objeto y los campos de Twenty al configurar un widget. Puedes filtrar un array por el valor completo o agruparlo por elemento. Un registro con varias etiquetas puede aparecer en varios grupos. Los campos disponibles dependen del tipo de dato y de los permisos de Twenty.
- **Menú.** En **Administración Omnichannel → Accesos**, cambia el nombre visible de las páginas y enlaces de Omnichannel. Para una vista o tabla nativa, **Crear acceso con nombre** añade un enlace al mismo destino.

Guías de [operación diaria](https://github.com/mikiguillamon/twenty-omnichannel-support/blob/v1.2.0/docs/OPERATIVA.md) y [dashboards](https://github.com/mikiguillamon/twenty-omnichannel-support/blob/v1.2.0/docs/DASHBOARD.md).
