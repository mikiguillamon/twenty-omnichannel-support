# Omnichannel Support 1.3.0

- El historial admite respuestas propuestas en correo, WhatsApp y los demás canales del plugin. Puedes editar el texto que generó n8n y pulsar **Enviar** para reanudar Wait con la versión aprobada.
- La API permite añadir una propuesta a partir del `messageId` de un mensaje entrante ya registrado. Puedes registrar después el mensaje enviado usando el `caseId` y el ID del proveedor.

Compatible con Twenty 2.50. Usa **Actualizar** en la instalación existente de Omnichannel Support. [Configurar el flujo de n8n](https://github.com/mikiguillamon/twenty-omnichannel-support/blob/v1.3.0/docs/INTEGRACION_N8N.md)
