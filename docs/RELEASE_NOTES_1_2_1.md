# Omnichannel Support 1.2.1

- **Conversaciones.** Pulsa el asunto de un correo o chat para leer su historial en la bandeja. Usa **Abrir ficha** desde el historial para consultar el registro de Twenty.
- **Mensajes.** La API de ingestión guarda los mensajes en texto plano, conservando los saltos de línea. Convierte los párrafos y enlaces del HTML a texto. El historial también convierte el HTML de mensajes antiguos al mostrarlos.
- **Etiquetas propias.** Elige una etiqueta visible o escribe su nombre completo para filtrar la bandeja. En dashboards, una conversación cuenta en cada grupo correspondiente a sus etiquetas propias.
- **Estados y canales.** Los gráficos y filtros de dashboards muestran los nombres configurados en Twenty, como «En curso» y «Correo».
- **Filtros de widgets.** Elige **Incluir** o **Excluir** para cada condición y edita o quita los filtros activos desde el mismo panel.

Compatible con Twenty 2.50. Actualiza la instalación existente desde el Marketplace.
